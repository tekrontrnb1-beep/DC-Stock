# Нийтлэгдсэн өгөгдөл

Самбараас **«📤 Нийтлэх»** товч дарж татсан `stock-data.json` файлыг **энэ фолдерт** хийнэ:

```
dashboard/data/stock-data.json
```

Дараа нь commit + push хийхэд та болон захирал хоёр
`…/minii-tuslakh/dashboard/` хаягаар ижил өгөгдлийг автоматаар харна.

> Локал дээр импортолсон өгөгдөл нь зөвхөн тухайн төхөөрөмжид (browser-т) хадгалагдана.
> Бусдад харуулахын тулд заавал нийтлэх (push) хэрэгтэй.
