# DC-Stock — Нөөцийн самбар

V9001 (DC center) агуулахын **үлдэгдэлтэй** бараануудын үлдэгдэл, **ABC/XYZ**,
**нөөц хоног (эргэц)**, төлөв, борлуулалт (гаралт), салбарын захиалга, түүхийг хянах
desktop самбар. (Tekron Support аппаас бүрэн тусдаа төсөл.)

---

## 🔄 Дата хэрхэн шинэчлэх вэ? (хамгийн чухал)

**3 алхам:**

1. **`import\` фолдер доторх файлуудаа шинэ файлаар соль** (нэрний хэвийг хадгал — доор үз).
2. **`refresh.bat`-г дабл-клик** хий (эсвэл `python build_data.py`).
   → бүх файлыг уншиж `data\stock-data.enc` (шифрлэсэн)-г шинэчилнэ.
3. **Нийтэл:**
   ```
   git add -A
   git commit -m "data update"
   git push
   ```
   → хэдэн минутын дараа та, захирал хоёр шинэ датаг автоматаар харна.

### `import\` доторх файлууд (нэрний хэв)

| Файл (хэв) | Юу вэ | Хэрэглээ |
|---|---|---|
| `상품마스터*.xlsx` | Барааны master | нэр, хэлтэс, **Өртөг үнэ**, худалдах үнэ |
| `9001 master*.xlsx` | V9001 бүртгэл | **төлөв** (`reOrdAppDt`), агуулах |
| `ABCXYZ*.xlsx` | ABC/XYZ | бараа бүрийн ангилал (`raw` sheet, `class` багана) |
| `Үлдэгдэл MM.DD.xlsx` | Өдрийн үлдэгдэл | огноо нь **файлын нэрнээс** (он = build_data.py доторх `YEAR`) |
| `Store order*.csv` | Захиалга + гаралт | өдрийн `TOTAL_ORDER_QTY`, `CALCULATED_OUTBOUND_QTY`, дүнгүүд |
| `Sales*.csv` | Жижиглэн борлуулалт | нийт тоо (барааны дэлгэрэнгүйд) |

- **Өдрийн үлдэгдэл** (`Үлдэгдэл MM.DD.xlsx`): шинэ өдрийн файлуудыг **нэмж** хийнэ (хуучныг устгахгүй — түүх хадгалагдана).
- **Захиалга/борлуулалт** (`Store order*.csv`, `Sales*.csv`): шинэ хугацааны файлуудыг мөн **нэг нэгээр нэмж** болно — ETL бүгдийг уншиж нэгтгэнэ. ⚠️ Хугацаа нь **давхцахгүй** байх ёстой (давхцвал давхар тоологдоно). Жнь: `Store order 05.25-05.31.csv`-г нэмнэ.
- **master / 9001 master / ABCXYZ**: шинэчилсэн файлыг тавихад **нэрээрээ хамгийн сүүлийнхийг** автоматаар сонгоно (хуучныг үлдээж болно, гэхдээ устгасан нь цэвэрхэн).
- Шинэ жил рүү шилжихэд `build_data.py` доторх `YEAR`-г солих хэрэгтэй (үлдэгдлийн файлд он байхгүй тул).

### Нууц код (passcode)

`import\passcode.txt` дотор нэг мөр нууц код байна. Үүгээр өгөгдөл шифрлэгдэнэ.
Энэ кодыг **захиралд тусдаа** (чат/утсаар) дамжуул — repo-д ороогүй (gitignore).
Кодоо солих → `passcode.txt`-г засаад `refresh.bat` дахин ажиллуул.

## 🚀 Анхны deploy (GitHub Pages)

1. **Нууц кодоо солих** (заавал): `import\passcode.txt`-д өөрийн код → `refresh.bat`.
2. GitHub дээр шинэ **public** repo үүсгэх: нэр `DC-Stock`.
3. Push (token-оо орлуулна; чатад бүү бич):
   ```
   cd "C:\Users\user\Desktop\DC-Stock"
   git add -A
   git commit -m "DC-Stock dashboard"
   git -c credential.helper= push -u "https://<USER>:<TOKEN>@github.com/<USER>/DC-Stock.git" main
   git remote set-url origin "https://github.com/<USER>/DC-Stock.git"
   ```
4. GitHub repo → **Settings → Pages → Deploy from a branch → `main` / root** → Save.
5. ~1-2 мин дараа: `https://<USER>.github.io/DC-Stock/`

## 📱 Утсанд App болгон суулгах (PWA)

Deploy хийсэн хаягийг утасны хөтчөөр нээгээд → **«Үндсэн дэлгэцэд нэмэх / Install»**.
DC-Stock апп болж суудаг (offline кэштэй). Нээхэд нууц код асууна.

## Тооцооллын тайлбар

- **Universe:** зөвхөн **үлдэгдэлтэй** (Үлдэгдэл файлд орсон) бараа. Бусад агуулах/устсан хасагдана.
- **Нөөцийн үнэ = Өртөг үнэ × үлдэгдэл** (худалдах үнэ биш).
- **Нөөц хоног (эргэц) = өнөөдрийн үлдэгдэл ÷ өдрийн дундаж зарцуулалт**, хоёр янзаар:
  - **борлуулалтаар** = ÷ өдрийн дундаж гаралт (Үлдэгдэл файлын «Өдрийн дундаж гаралт»)
  - **захиалгаар** = ÷ өдрийн дундаж салбарын захиалга
- **Төлөв** = 9001 master-ийн `reOrdAppDt` (Энгийн / Түр зогссон / Устсан / Шинэ / ...).
- **Борлуулалт** = DC-ийн **гаралт** (outbound). Жижиглэн Sales.csv нь барааны дэлгэрэнгүйд.

## Ажиллуулах (локал)

```bash
python -m http.server 5546      # дараа нь http://localhost:5546
```
Локал дээр (plaintext `data\stock-data.json` байгаа тул) нууц код асуухгүй.
Нийтэлсэн хаяг дээр зөвхөн `.enc` байх тул нууц код асууна.

## Бүтэц

- `index.html`, `dashboard.css`, `dashboard.js` — самбар (vanilla JS, SheetJS + Chart.js CDN)
- `build_data.py` — ETL: `import\` → `data\stock-data.json` (локал) + `data\stock-data.enc` (нийтлэх)
- `refresh.bat` — нэг товшилтоор ETL ажиллуулна
- `icon.svg` — favicon
- Шифрлэлт: AES-256-GCM + PBKDF2-SHA256 (browser Web Crypto-оор тайлна)
- `.gitignore`: түүхий файл (`import/`), plaintext (`data/stock-data.json`), `passcode.txt` — commit хийгдэхгүй
